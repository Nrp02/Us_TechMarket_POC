# 04: Groq-powered Today's Story narrative generation

**What to build:** A scheduled job produces an 8-section narrative per stock (headline with a selected/justified news item, sector/market/peer comparison, company-vs-market classification, unusualness vs. history, causal explanation, business/fundamentals, peer/sector relation, YTD takeaway) using a new AI provider, and stores it for the page to read later. Verified by triggering the job manually and reading the stored JSON for a few stocks — no UI yet.

**Blocked by:** 03 (needs the computation-engine payload as the call's input).

**Status:** done — implemented and verified against real production data (`npx tsc --noEmit` and `npm run lint` clean; no new automated tests, per this ticket's own testing decision — the Groq HTTP client and DB layer are explicitly out of scope for the test seam). Migration `0012_stories.sql` applied. Not yet wired into `queries.ts`/the page (ticket 05).

- [x] A new AI client is wired up against the chosen Groq model (`src/lib/groq.ts`, `openai/gpt-oss-20b`), separate from and unaffected by the existing Gemini client used for news summaries.
- [x] The narrative call's schema has exactly 8 sections, each populated from the assembler's payload; no section invents a number the assembler didn't already compute.
- [x] The headline section states the existing significance result plus one AI-picked news item and a reason grounded in that article's own content/metadata — never a price-causation claim (that stays the explanation section's job). The picked article's headline/URL/timestamp are resolved server-side from the model's index pick, never taken from text the model wrote, so it cannot invent one.
- [x] The causal-explanation and peer/sector-relation sections may infer a plausible connection from the data given, without requiring a source article to state it explicitly, but still never predict future price movement and never offer investment advice.
- [x] Every section falls back to a fixed, honest line when the given data doesn't support even an inferred read (mirrors the existing fallback-line behavior).
- [x] The job processes one stock per AI call, not a multi-stock batch.
- [x] The job is paced across its existing schedule (2 stocks per scheduled run, added to `scripts/setup-cron.mts` as a second job on the same 12-tick window `daily-summaries` already uses) so all 20 tracked stocks get a same-day story without exceeding the provider's per-minute rate limit. **Not yet provisioned against the live Supabase Cron** — the script change is committed but `npm run setup-cron` has not been run; that's a real, infra-affecting action left for the owner to trigger deliberately.
- [x] On a rate-limit response, the job skips that stock for the current run without retrying immediately or throwing, and a later run in the same day picks up any stock still missing a story. Verified live: back-to-back manual runs hit Groq's real per-minute token limit, `skippedRateLimited` reported it without throwing, and the stock generated cleanly on the next run.
- [x] Triggering the job manually (`generateStories('2026-09-25')`) and reading the stored result for 3 stocks (NVDA, AAPL, MSFT) shows all 8 sections populated with numbers matching `price_cache`/`daily_closes` exactly (peer average, vs-sector, vs-market deltas all hand-verified to the raw figures). One real bug was found and fixed during this verification: the prompt originally gave the model only the *divergence* from sector/market, never the sector/market's own change% — a negative divergence against a rising sector produced a story claiming the sector "declined." Fixed by adding both the absolute and the divergence figures to the prompt, each explicitly labeled. `fundamentals` correctly shows the fixed no-data line for all three, since `fundamentals` is still an empty table in production (ticket 02's own unverified checkbox — its backfill was never triggered; unrelated to this ticket). `daily_closes` was empty too until this ticket ran the ticket-01 backfill script to get real test data; it now holds a live year of closes for all 25 symbols.
