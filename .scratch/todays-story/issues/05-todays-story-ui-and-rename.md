The page and its nav entry now read "Today's Story" instead of "Today's Activity" everywhere a visitor sees text, with no change to the URL, shortcuts, or any other existing content on the page.

**Blocked by:** 04 (needs a real stored narrative to render).

**Status:** built — `npx tsc --noEmit`, `npm run lint`, `npm test` all clean; verified against real production data for NVDA (`story_date = 2026-09-25`) via a production build + `npm start` + curl. Live-browser responsive verification (last checkbox) was **not done** this session — the Claude in Chrome extension was not connected — so that item is unchecked rather than falsely claimed.
