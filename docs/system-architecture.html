overview

System overview

ภาพรวมทั้งระบบ: read path ของผู้ชม (ซ้าย) กับ write path ที่ pg_cron เป็นตัวสั่ง (ขวา) Compute engine คือชั้นที่แปลง raw rows ให้เป็น input ของ AI

refresh

Market refresh pipeline

ข้อมูลดิบจาก 4 แหล่งผ่านการ normalize ก่อนบันทึก ราคาปิดใช้ print 16:00 ของ Yahoo แทน quote ของ Finnhub ที่ขยับไปตามราคาหลังตลาดปิด ส่วน snapshot จะ snap ลง grid 15 นาที

stock engine

Today's Story compute engine

market engine

story gate

Story generation quality gate

daily summary

What Happened Today (Gemini)

generateDailySummaries

  • loadDayDataBatch อ่าน snapshots + news ของ Top 20 ใน 2 round trip
  • rebuild timeline ทุกหุ้น (มี deadline 25s) แล้วจึงสร้าง input
  • Gemini gemini-3.5-flash 1 call ต่อ batch 5 หุ้น, retries 0
  • sync earnings calendar ลง events

Output
